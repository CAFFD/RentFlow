# Recursos para a apresentação

Esta pasta contém recortes literais do código e extratos de evidências reais. Nenhum resultado foi recriado. Os arquivos `.txt` foram preparados para abertura no VS Code em zoom de apresentação e captura manual.

## Organização

- `01-code`: trechos pequenos do código original. O índice informa arquivo e linhas.
- `02-rabbitmq`: consultas atuais e roteiro das telas do painel.
- `03-experiments`: resultados selecionados das transcrições versionadas.
- `04-architecture`: diagramas Mermaid editáveis.

Os PNGs usam o código original e as transcrições reais dos experimentos. Consulte `CAPTURAS-MANUAIS.md` para repetir capturas sem exibir credenciais.
